## Identity

The user starts the main agent in the project folder with `fld claude`. It starts the daemon when needed, then the user's own Claude Code session as the agent `main` with the `main` tag. `fld claude` continues the last main session, also after `/clear` or `/resume` inside it, and `fld new` starts a new one. `fld claude --name <name>` picks another name, and the arguments after `--` go to `claude`. `fld claude` appends the main agent prompt to the session's system prompt on every start and resume: the prompt that ships with fold, or `.fold/roles/main.md` when the project has one; fold adds its shared rules and its default engineering practices after either. A system prompt flag of the user's own after `--` replaces it. fold starts every other agent itself: the leads, the task workers and the reviewers, each with its agent name and the prompt of its role (see the Worker agents section of `fold-main`). A session opened in the project by hand has no agent name; it calls `register_agent(name, tags?)` first. It has the fold tools when fold is in the user's own Claude Code config. `fld setup` and the first `fld claude` offer to add fold there, and `fld setup --claude` adds it. `fld claude` and the workers of fold get the tools from fold in all cases.

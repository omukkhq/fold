# Security policy

## Report a vulnerability

Do not report a security problem in a public issue. Report it privately through a [GitHub security advisory](https://github.com/omukkhq/fold/security/advisories/new) ("Report a vulnerability" in the repository's Security tab).

Include:

- what the problem is and what an attacker can do with it;
- the steps or a small proof that shows it;
- the `fld --version` output and your system;
- whether the problem is public anywhere.

We answer in the advisory, agree on a fix and a release date with you, and credit you in the advisory unless you ask us not to.

## Supported versions

fold is in early development. We fix security problems in the latest release only.
